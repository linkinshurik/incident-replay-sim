# Definition of Done (DoD)

## Обов’язкові гейти для кожного PR
1. Репозиторій збирається локально і в CI.
2. `make fmt` — без змін після форматування.
3. `make lint` — без помилок.
4. `make test` — всі тести зелені.
5. `make build` — успішно.
6. `make k6-smoke` — проходить (1 VU, 30s).
7. README оновлено, якщо змінюється спосіб запуску/конфіг.

## Мінімальні стандарти коду
- Жодних секретів у репо (ключі/токени/паролі).
- Конфіг через env vars (приклад у `.env.example`).
- Логи структуровані (JSON або key=value).
- Усі зовнішні залежності зафіксовані (go.mod/package-lock).

## Спостережуваність (мінімум)
- `/healthz` — 200 OK.
- `/metrics` — доступний (навіть якщо спочатку заглушка).
